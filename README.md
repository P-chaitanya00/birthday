Built with modern CSS3 3D animations, Web Audio API procedural synthesis, frosted glassmorphism, dynamic photo lightboxes, and client-side persistence.

## ✨ Features at a Glance

| # | Feature | Description |
|---|---|---|
| 1 | **📅 Calendar Countdown** | November 18–22 countdown timeline with glowing heart checkpoint nodes & milestone celebration banner. |
| 2 | **🎵 Procedural Ambient Audio** | Built-in Web Audio API synthesizers playing warm arpeggios automatically with toggle pill. |
| 3 | **✨ Floating Canvas Particles** | 60 FPS HTML5 canvas physics rendering floating romantic hearts & sparkle cursor follower. |
| 4 | **👑 Hero Memory Showcase** | Rose-gold gradient titles with 3 portrait memory frames styled in antique gold borders. |
| 5 | **🎂 3D Patisserie Cake** | Flickering candles with tap/blow-out detection, smoke puff animations, chime chimes & surprise card. |
| 6 | **📜 Wax-Sealed Love Letter** | Classic postal envelope cover opening into a full-page frosted glass blur parchment modal. |
| 7 | **💌 Reasons Deck** | 3D interactive flip deck with 10 romantic cards highlighting her unique qualities. |
| 8 | **📸 Snapshots Filmstrip Reel** | 5-photo responsive carousel with left/right circular screen-edge arrows & romantic photo lightbox. |
| 9 | **🎁 Realistic 3D Gift Box** | Velvet crimson gift box with satin gold ribbon & 3D bow; unboxes with confetti to reveal secret note: *"as soon as u see me come and give me a tight hug"*. |
| 10 | **📌 Sweet Wish Wall** | Interactive cork-board with sticky notes that persist across reloads in browser `localStorage`. |
| 11 | **⚙️ In-App Personalizer** | Modal dialog allowing instant customization of names, Telugu/English love letters, and photo URLs. |

👉 *For detailed documentation of every feature, see [docs/FEATURES.md](docs/FEATURES.md).*

## 🚀 Quickstart & Local Setup

### 1. Clone the repository
```bash
git clone https://github.com/P-chaitanya00/birthday.git
cd birthday
```

### 2. Launch Local Server
```bash
# Python 3
python -m http.server 8080
```
Open **[http://localhost:8080](http://localhost:8080)** in any modern browser.

## 🌐 Free 1-Click Hosting on GitHub Pages

1. Open **[Settings > Pages](https://github.com/P-chaitanya00/birthday/settings/pages)** on this repository.
2. Select branch `main` and folder `/ (root)`.
3. Click **Save**.
4. Your website will be live in 1-2 minutes at:
   **`https://p-chaitanya00.github.io/birthday/`**

👉 *For Netlify and Vercel hosting guides, see [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md).*
